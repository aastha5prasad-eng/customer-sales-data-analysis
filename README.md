# Customer Sales Data Cleaning & Analysis

## Project Overview

This project focuses on cleaning and analyzing customer sales data using Python and Pandas.

## Work Performed

- Removed duplicate records
- Handled missing customer information
- Handled missing quantity and price values
- Standardized date format
- Added a Total Sales column
- Performed product-wise sales analysis
- Performed city-wise sales analysis
- Created a sales visualization

## Tools Used

- Python
- Pandas
- Matplotlib
- CSV

## Output

The project generates:

- Cleaned customer dataset
- Sales analysis
- Product-wise sales chart
## Project Results

- Cleaned and prepared customer sales data for analysis.
- Removed duplicate records and handled missing values.
- Performed product-wise and customer-wise sales analysis.
- Generated visual insights using Python and Pandas.
- Created a sales-by-product visualization for easy interpretation.
